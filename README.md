## 🚀 Featured Projects

### 📝 [NoteNest — AI-Powered Note Taking App](https://github.com/Prachi-1606/NoteNest)
> Started as a simple note app. Slowly grew into something with AI built in.

- 🤖 Built a **RAG-lite AI pipeline** which pulls top 5 relevant notes via multi-keyword search and feeds them as context to the LLM, so responses are grounded in *your* data, not hallucinated
- ⚡ Live search with **400ms debounced fetch** returning fragments without full page reload
- 🧠 3 AI features — Q&A from notes, folder summarization, and auto tag suggestion all over a single LLM API integration

**Tech:** `Java` `Spring Boot` `Spring Data JPA` `Thymeleaf` `LLM API` `SQL`
